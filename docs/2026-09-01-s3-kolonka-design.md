# s3-kolonka — дизайн первой прошивки

Дата: 2026-09-01  
Плата: Waveshare ESP32-S3-Touch-LCD-1.85C V2 BOX

## Решение

Пишем своё приложение на ESP-IDF. Инициализацию дисплея, тача, EXIO и кодека не изобретаем — берём из официального Waveshare ESP-IDF example. XiaoZhi не форкаем.

## Первый вертикальный срез

Цель: после `idf.py flash` на круглом экране своя заставка `s3-kolonka`, тач живой, устройство не показывает демо Onboard/Music.

Вне скоупа этого среза: wake-слово, LLM, HA, YouTube, свой сервер.

## Дальше

1. Воспроизведение и запись через ES8311/ES7210.
2. Wi-Fi + HTTPS/WebSocket к своему серверу.
3. STT → Ollama (и облачные LLM) → TTS.
4. Home Assistant.
5. Музыка.

## Ограничения

- ESP32 не хостит LLM.
- YouTube не крутится на плате — только через сервер.
- Wi-Fi только 2.4 GHz.
